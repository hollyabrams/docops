<h2 id="get-health">Documentation health</h2>

Returns the current health of the documentation system and the individual checks used to calculate the overall score.

### Request

<Endpoint method="GET" path="/api/v1/health" />

This operation does not require authentication or parameters.

<ApiRequest method="GET" path="/api/v1/health" />

### Response

A successful request returns a `200` response with a JSON object containing the overall score, status, and individual health checks.
